=== Paez Tree Service — WordPress Theme ===

INSTALL
1. In WordPress admin, go to Appearance → Themes → Add New Theme → Upload Theme.
2. Choose paez-tree-service.zip and click Install Now, then Activate.
3. Done — the homepage renders the full one-page design automatically.

NOTES
- Images are loaded from your existing paeztreeservice.com media library, so nothing extra to upload.
- The "Get a Free Estimate" form is markup only. To make it send email, connect it
  to a form plugin (WPForms, Contact Form 7, Fluent Forms) or ask us to wire it up.
- The 10% OFF promo strip is in index.php near the top — delete that block to remove it.
- Phone, address and license number are plain text in index.php if you ever need to edit them.
